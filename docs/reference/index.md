# Package index

## Bulk RNA-seq

Compare heterogeneity between groups of bulk samples, either predefined
or stratified by the expression of candidate genes.

- [`bulk_het()`](https://ssobt.github.io/txnheterogeneity/reference/bulk_het.md)
  : bulk_het()
- [`plot_bulk_het()`](https://ssobt.github.io/txnheterogeneity/reference/plot_bulk_het.md)
  : plot_bulk_het()

## Single-cell RNA-seq

Per-condition transcriptome-wide coefficient of variation from a Seurat
object.

- [`sc_het()`](https://ssobt.github.io/txnheterogeneity/reference/sc_het.md)
  : sc_het()
- [`plot_sc_het()`](https://ssobt.github.io/txnheterogeneity/reference/plot_sc_het.md)
  : plot_sc_het()

## Single-cell ATAC-seq

Open-chromatin heterogeneity from 10x fragment files, using ArchR for
peak calling.

- [`scATAC_het()`](https://ssobt.github.io/txnheterogeneity/reference/scATAC_het.md)
  : scATAC_het()
- [`plot_scATAC_het()`](https://ssobt.github.io/txnheterogeneity/reference/plot_scATAC_het.md)
  : plot_scATAC_het()
